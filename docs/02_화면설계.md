시안 파일은 `design/mockups/`에 있다. 브라우저로 열어 동작까지 확인할 수 있다. 시안의 데이터는 모두 가상이다.

## A. 회의자료 작성 화면

**본문에는 고른 것 하나만**(2026-10-21): 왼쪽에서 고른 새 메모 입력 / 메모 1개(「이 메모에서 나온 이슈」 칩) / 이슈 1개(이전·다음 이슈, 사진은 큰 사진 1장 + 썸네일 줄). 3단 구성(2026-10-21 재배치): **왼쪽** 메모 목록(+ 새 메모)·블록 목차·이어받기 / **가운데** 지금 연 메모 하나(줄 번호·AI 정리·원문 수정)와 블록 편집 / **오른쪽** 확정 전 체크(스크롤해도 따라옴)·미리보기·유사 사례·내보내기. 부서 이동은 머리줄 「부서 바꾸기」.
화면 폭 1240px 아래에서는 오른쪽이 아래로, 860px 아래에서는 한 줄로 쌓인다.

작성 단계 표시: ① 메모 → ② AI 정리 → ③ 검토·편집 → ④ 확정·내보내기

## B. 회의 · 팀 보고서 화면

- 상단 요약 4칸: 이번 주 신규 / 진행 중 / 종결 승인 대기 / 장기 미결(4주 이상, 기준은 설정값)
- **부서별 제출 현황**: 01~07 순서, 블록 수, 상태 배지. 버튼: 회의 화면 시작, PPT 내보내기
- **회의 중 이슈 등록**
  - 바로 등록: 제목 + 담당 부서 → 등록. 다음 주 그 부서 섹션에 "회의 발생" 표시로 등장
  - 회의록 메모 추출: 메모 붙여넣기 → AI가 이슈 후보 생성 → 등록 또는 기존 블록에 연결
- **종결 승인 대기**: 블록 유형, ID, 부서, 경과 주, 조치 내용. 승인 → 사례 카드 승격 / 보류 → 다음 주 재검토
- 회의 화면 시작: 부서 순서대로 한 화면씩 넘기는 발표 모드, 블록별 코멘트 기록

## C. 지식창고 화면

- 검색창: 자연어 질문. 결과 위에 **AI 요약**(근거 사례 ID 인용 필수)
- 종류 필터: 전체 / 사례 / 공유정보 / 지표 추이 / 사진 / 표준 용어집 (개수 표시)
- 왼쪽 필터: 호선, 장비·시스템, 선주·선종, 기간 (개수 표시)
- 결과 카드: 사례 = 증상 / 원인 / 조치 3칸 + 출처(주차, 부서 이동, 사진 수)
- 오른쪽: 선택한 사례의 주차별 이력 타임라인, 연결된 지식 그래프 미니맵

## D. 장비 허브 화면

- **현장 표기로 찾기**: "2511 DG2" 입력 → 호선 SN2511 + 발전기 No.2 → `EQ-SN2511-GE-02`. 못 찾으면 "미확인" 표시
- **기준정보 카드**: 호선, 선종·선주, 자매선, 시스템 계층, 장비 모델, 시운전 항목, 담당 부서, 별칭
- **연결 지도**: 탑재 장비 중심, 호선·자매선·시스템·진행 이슈·시운전 항목·장비 모델·동일 모델 탑재·주요 원인. 노드 클릭 → 근거 패널로 이동
- **선행 사례 알림**: 자매선 같은 위치 장비의 과거 동일 증상 → 점검 권장
- 근거 패널: 이 장비의 이력 / 동일 모델 다른 호선(자매선 강조) / 모델의 원인 순위 / 부위별 사진

## 공통 UI 규칙

- 블록 유형 색: 공유정보 `--share`, 문제점 `--danger`, 이슈 `--signal`, 대시보드 `--accent`, 종결 `--ok`
- 확신 낮음 = 노란 테두리(`--signal`), 빈 필수 = 빨간 테두리(`--danger`)
- 모든 숫자는 `tabular-nums`, ID는 고정폭 글꼴
- (2026-10-22) 결정 필요 `--decide`, 회의 종류는 테두리 배지, 글자 크기 `--fs-1~5`, 회의자료 색 `--slide-*`(네이비) — `docs/06` §3-2
- 화면 상태(선택 탭 등)만 브라우저 저장소에 둔다. 업무 데이터는 항상 서버 DB.
