## 4. 가져오면 안 되는 것

| 샘플 | 문제 | 우리 규칙 |
|---|---|---|
| 「사실 수정 시 모든 회의자료 즉시 역반영」 | 발행한 자료가 바뀌면 회의에서 실제로 본 내용이 남지 않는다 | 반영은 이슈와 **발행 전** 자료까지만. 발행본은 판으로 고정하고 「변경 n」만 표시 (06 §2-1) |
| Tailwind CDN, Google Fonts(Pretendard·Inter·JetBrains Mono) | 사내망에서 불러오지 못한다 | 로컬 글꼴 Meeting Sans KR, `tokens.css` |
| hex 직접 사용, 이모지 아이콘 | 색 의미가 흩어지고 다크 모드가 깨진다 | 토큰만 쓴다 |
| 영문 머리말(「HOME · THIS WEEK WORKLOAD」, 「F16 · WEEKLY METRICS」) | UI 문구는 한국어로 쓰는 규칙에 어긋난다 | 한국어 |
| 작성자 실명 표시(「김 과장」) | 개인정보 최소수집 규칙(공통 규칙 7)에 어긋난다 | 부서만 표시하거나 마스킹 |
| 한 파일 SPA·JS 상태 | 앱 구조와 다르다 | 서버 렌더링. 상호작용은 지금처럼 작은 JS 모듈로 |
| 지식창고와 장비 허브를 한 탭으로 | 들어오는 목적이 다르다(찾기 대 장비 하나 보기) | 메뉴는 나눠 두고, 질문 답 옆에 허브 링크 |

## 6. B안 — 덜어낸 것과 이유 (2026-10-23)

사용자 요청은 세 가지였다: 시인성, 불필요한 기능·UI 정리, **진행이 매끄러운지**(작업 순서를 보여 주는 것보다 실제로 막힘 없이 이어지는 것). 시안은 `design/mockups/v2b-*.html` 이고, 목록과 클릭 수는 `design/mockups/README.md` 에 있다.

| # | A안 | 덜어내거나 합친 것 | 이유 |
|---|---|---|---|
| R1 | 부서 회의자료 · 팀장 정보회의 구성이 다른 화면 | 「회의자료 편집」 하나(`?kind=`) | 같은 일(후보 → 개요 → 미리보기)을 두 번 배우지 않게 |
| R2 | 보기 화면에 순서·수정 버튼 | 보기는 읽기 전용 + 「편집」 하나 | 읽는 사람이 대부분이고, 고치는 곳은 하나여야 한다 |
| R3 | 제출 버튼 두 곳(홈·부서 자료) | 부서 자료 편집 한 곳 | 어디서 내는지 헷갈리지 않게 |
| R4 | 가져오기 입구 셋 | 「가져오기」 하나(메모·메일·파일) | 들어오는 길이 달라도 확인 방법은 같다 |
| R5 | 작업대 탭 5개·초안 형태 4개·저장 버튼 | 한 줄 흐름, 붙이기 버튼 하나, 자동 저장 | 위에서 아래로 한 번 훑으면 끝 |
| R7 | 회의 카드마다 「설정」 | 없앰 | 정기 회의는 자동 생성 |
| R8 | 시안 설명 띠 | 접히는 한 줄 | 화면 공간 |

**매끄러운 진행 장치**
- 끝내면 다음으로: 한 줄 Enter → 다음 칸, 초안 완료 → 다음 초안, 판정 → 다음 조각, 기록 → 다음 안건.
- 확인 창 대신 되돌리기: 빼기·제출·발행·종결 승인.
- 다 끝나면 다음 할 일을 알려 준다(홈의 「이번 주 할 일을 마쳤습니다」, 작업대의 「홈으로 →」).
- 주 버튼은 화면마다 하나, 바닥 고정 줄 오른쪽에 둔다. 이름이 그 결과를 말하고(「제출」), 누른 뒤에는 다음 단계로 바뀐다(「공유회 자료 보기 →」).
- 단축키: J/K 이동, Ctrl+S 주 동작, 발표 ←/→.

**스타일 개정(2026-10-23)** — 「테두리만 강조돼 별로」 의견으로 iPadOS 27 그룹 목록 스타일로 다시 그렸다. 테두리 0(굵은 선 측정 0개), 회색 바탕 위 흰 카드, 섹션 머리는 카드 밖 회색 글자, 큰 제목, 왼쪽 사이드바, 반투명 없음. Apple 키트는 라이선스상 원칙만 참고.

**시인성**
- 화면: 글자 13·15·17·22·30, 본문 대비 18:1, 보조 글자 9:1, 진한 유형 라벨(흰 글자 6.5~8.9:1), 상태는 기호와 글자를 함께 쓴다.
- 발표 장: 1920×1080 기준으로 본문 최소 26px(측정함), 늘 흰 바탕, 「결정 필요」는 굵은 상자. 아래 띠에 「n / 전체 · 다음 안건」을 둔다.
- 앱 반영 전에 A안과 B안 중 하나를 고른다(또는 섞는다).
